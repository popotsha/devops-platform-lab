# GitHub Pages — Community Edition

This folder powers the public GitHub Pages site for the **Community Edition** and promotes CyberInfoware **Premium** editions (V1 / V2 / V3).

## Enable Pages

1. Push this repository to GitHub (public).
2. **Settings → Pages → Build and deployment**
3. Source: **Deploy from a branch**
4. Branch: `main` (or your default) · Folder: `/docs`
5. Save — your site will be at `https://<user>.github.io/<repo>/`
